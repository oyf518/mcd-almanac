# 麦门老黄历（MCD Almanac）

> 📜 每日玄学点餐指南 —— 把麦当劳的实时数据变成一份能截图分享的老黄历。

每天早上问一句"今天麦当劳吃什么"，本 Skill 会调用麦当劳 MCP 拿到**当天活动、卡包券、积分、抽奖状态和你的历史订单**，按一套可复现的规则推算出：

- 🔶 **今日宜**：该参加的活动、该领的券、该花的快过期积分
- ⛔ **今日忌**：别重复昨天的餐、别连续上头、别让券默默过期
- 🍀 **幸运单品 / 💰 财气 / 🎰 手气 / 📈 幸运指数**
- 🔮 **麦门签文**：按宜忌命中的档位抽一条
- 📅 **近期机缘**：未来 3 天内要开始的活动提醒

玄学是壳，数据是核——每一条宜忌后面都标注了真实数据来源，不做无依据的胡编。

## 目标用户

- **麦门信徒**：每天纠结"吃什么"，想要一个带仪式感的决定
- **羊毛党**：怕券过期、怕积分清零、怕错过活动，需要每日提醒
- **麦当劳重度用户**：连吃太多天时，需要一份"忌重复"的温柔劝阻
- **AI Agent 玩家**：想体验"用 MCP 实时数据驱动内容生成"的 Skill 范式

## 环境要求

1. 一个支持 **Agent Skill**（`SKILL.md`）的客户端：Trae、Claude Code、WorkBuddy 等
2. 麦当劳 MCP Token（申请方式见 [mcd-mcp-server](https://github.com/M-China/mcd-mcp-server)）

## 安装方法

### 1. 配置麦当劳 MCP

在客户端的 MCP 配置中加入（替换 `YOUR_MCP_TOKEN`）：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_TOKEN"
      }
    }
  }
}
```

### 2. 安装本 Skill

- **目录方式**：把本仓库整个目录放入客户端的 skills 目录（如 `~/.trae/skills/mcd-almanac`、`.claude/skills/mcd-almanac`），确保 `SKILL.md` 位于该目录根部。
- **仓库方式**：`git clone https://github.com/{你的账号}/mcd-almanac.git` 后按上面的路径放置。

安装后客户端会自动识别 `SKILL.md` 中的 `name` 与 `description` 进行触发。

## 使用示例

**示例 1：每日打卡**

```
用户：今天麦当劳吃什么？
助手：（调用 mcd-mcp 生成卡片）

📜 麦门老黄历 · 2026-10-09 周五
🔶 今日宜：9.9 元早餐两件套今天还有（活动日历）／先领 3 张麦麦省券（可领券）
⛔ 今日忌：昨天刚吃过麦辣鸡腿堡，换口味（历史订单）
🍀 幸运单品：麦旋风（约 230 kcal/份）
📈 幸运指数：★★★★
🔮 签文：金拱门开，券在袋中；今日出手，宜早不宜迟。
> 懒人结论：今天吃早餐两件套，先把券领了，别重复昨天。
```

**示例 2：周运**

```
用户：这周运势如何？
助手：（读取活动日历未来 7 天，输出每日一行宜忌 + 本周最大机缘）
```

**示例 3：把宜办了**

```
用户：帮我把今天的"宜"都办了。
助手：我将执行：① 领取 3 张麦麦省券；② 用 8 快过期积分兑换小食。确认吗？
```

**示例 4：吃得怎么样**

```
用户：我最近是不是吃太多了？
助手：（用历史订单 + 营养数据做"坦白局"式回顾，不生成完整黄历）
```

## 隐私与安全

- 本 Skill 全程**只读查询为主**，仅在用户明确确认后才执行领券/兑换/抽奖等写操作。
- 不存储、不上传任何 Token 与个人数据；MCP Token 由客户端配置文件自行保管，本仓库不含真实 Token。
- 输出内容不构成医疗或营养建议。
