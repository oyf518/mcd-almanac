# 宜忌判定规则与话术库

所有判定只依赖麦当劳 MCP 返回的真实字段。每个判定给出：触发条件 → 写进黄历的话术（可微调语气，不得改变事实）。

## 一、数据 → 信号映射

### 1. 时间信号（`now-time-info`）

| 字段 | 信号 |
| --- | --- |
| `dayOfWeek` 周一~周五 | 工作日；若活动日历含当天早餐活动 → 宜：工位早餐两件套 |
| `dayOfWeek` 周六/周日 | 周末；宜堂食/主题活动类活动，忌赶早餐活动（多数早餐活动仅工作日） |
| `formatted` 时段 | 11:00 前 → 早餐语境；11:00–14:00 → 午餐语境；17:00 后 → 晚餐语境 |

### 2. 活动信号（`campaign-calendar`）

- 活动日期**包含今天** → 宜：参加「活动标题」（素材直接取活动标题与介绍中的关键利益点，如"9.9 元早餐两件套"）。
- 活动**在未来 3 天内开始** → 写入"近期机缘"，提示定闹钟。
- 活动为**往期** → 不作为今日宜；若与用户昨天订单撞车，可写"忌：错过昨日截止的 XX"（仅当往期活动截止日为昨天）。

### 3. 券信号（`available-coupons` / `query-my-coupons`）

| 条件 | 判定 |
| --- | --- |
| `available-coupons` 中有"待领取/可领取"状态的券 | 宜：捡漏，把 N 张麦麦省券领了 |
| `query-my-coupons` 中某券 `datetimeText` 显示**今天最后一天可用** | 忌：让到期的券默默过期（点名券的 `discountDesc`） |
| 我的可用券 ≥ 5 张 | 财气指数上浮；宜：先用券再点单 |
| 我的可用券 = 0 且可领券 > 0 | 宜：先领券，忌原价点单 |

### 4. 积分信号（`query-my-account`）

| 条件 | 判定 |
| --- | --- |
| `currentMouthExpirePoint` > 0 | 宜：先把本月要过期的 N 积分花掉（可去麦麦商城换点啥） |
| `availablePoint` ≥ 商城热门兑换档位（如 500/1000） | 宜：兑换；提示可用 `mall-points-products` 查可换什么 |
| `availablePoint` < 100 | 忌：拿仅剩的积分去抽 `draw-lottery`（若抽奖单次消耗高于余额则忌改口为"手气暂缺"） |

### 5. 抽奖信号（`query-lottery-info`）

| 条件 | 判定 |
| --- | --- |
| 活动进行中且用户剩余次数 > 0 | 宜：一发入魂（注明剩余 N 次） |
| 活动进行中且剩余次数 = 0、积分充足 | 平常签：手气看缘分，勿上头 |
| 活动未开始/已结束 | 不写抽奖相关宜忌，只在"机缘"里提一句 |

### 6. 历史订单信号（`order-list`）

| 条件 | 判定 |
| --- | --- |
| 昨天有订单，且今天想点同款/黄历推荐同款 | 忌：昨天刚吃过 XX，今天换个口味 |
| 连续 ≥ 3 天有订单 | 忌：连吃 N 天，麦门也需要喘息（麦当劳也建议均衡饮食，语气要调侃不要说教） |
| 昨天无订单（"破戒"间隔 ≥ 1 天） | 宜：久违的第一口最香 |
| 近 3 天订单中出现多次高脂/高钠单品（用 `list-nutrition-foods` 对照 fat/sodium 字段） | 忌：再来一份同类（点名该单品），宜搭配套餐里加沙拉/牛奶类 |

### 7. 营养信号（`list-nutrition-foods`）

- 用于给"幸运单品"标注热量区间，和对照昨天订单的重复检测。
- 表述只用"约 X kcal/份"的事实句，不做健康结论。

## 二、幸运指数算法（确定性，可复现）

基础 70 分，逐项累加，封顶 100、保底 40：

| 信号 | 加减 |
| --- | --- |
| 今天有正在进行的活动 | +8 |
| 有可领的新券 | +6 |
| 有今天到期的券 | −5（属于"机缘提示"而非坏运） |
| 本月有过期积分未用 | −4 |
| 抽奖有剩余次数 | +6 |
| 昨天无订单 | +4 |
| 连续 ≥ 3 天有订单 | −6 |
| 周末 | +3 |

映射：≥90 → ★★★★★；80–89 → ★★★★；70–79 → ★★★；60–69 → ★★；<60 → ★。

财气指数：以"可用券数 + 可领券数 + 是否有过期积分"映射（0 项 → ★；1 项 → ★★；2 项 → ★★★；3 项 → ★★★★；4 项及以上 → ★★★★★）。
手气指数：抽奖有剩余次数 → ★★★★；无次数但积分充足 → ★★；积分紧张 → ★。抽奖活动未开放 → 显示"休市"。

## 三、签文库（三档，按命中情况选用）

**宜多于忌（整体上上签）**

1. 金拱门开，券在袋中；今日出手，宜早不宜迟。
2. 昨日未破戒，今日第一口最香；点你所爱，爱你所点。
3. 活动临门，积分未冷；麦门今日，诸事皆宜。

**宜忌相当（中签）**

1. 有券可用，有活动可参；不贪不弃，按需点单即可。
2. 常餐常安，勿因小券乱加单；吃饱刚好，是为麦门正道。
3. 积分不多不少，正好换份小食；大单再等机缘。

**忌多于宜（下签）**

1. 连日饕餮，钱包与肠胃同虚；今日宜淡，一杯咖啡足矣。
2. 券将过期而未用，积分将清零而未花；宜先清理，再谈点单。
3. 昨日同款今日再点，口腹之欲易生腻；换个小的，换个心情。

## 四、写法要求

- 每条宜/忌一句话，≤ 30 字，口语化、可调侃，不说教。
- 数据来源用括号标注：（活动日历）（卡包券）（积分账户）（抽奖）（历史订单）（营养库）。
- 禁止出现编造的活动名、券名、餐品名；话术库中的餐品名仅作占位示例，实际输出必须替换成工具返回的真实餐品。
