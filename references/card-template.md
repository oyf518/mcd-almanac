# 老黄历卡片模板

输出时严格使用下面的结构。`{...}` 为按数据填充的占位符；数据缺失的板块改为"天机暂未泄露"，不要整块删除。

```markdown
📜 **麦门老黄历 · {yyyy-MM-dd} {星期}**
🕒 时辰：{时段：早八/午时/晚高峰}　|　{周末显示"休"，工作日显示"班"}

——————————————
🔶 今日宜
1. {宜_1}（{来源}）
2. {宜_2}（{来源}）
3. {宜_3}（{来源}）

⛔ 今日忌
1. {忌_1}（{来源}）
2. {忌_2}（{来源}）

🍀 幸运单品：{餐品名}（约 {X} kcal/份，{来源}）
💰 财气：{★×N} — {一句话，如"3 张券在包，1 张今天到期"}
🎰 手气：{★×N / 休市} — {一句话，如"抽奖还剩 2 次，宜一发入魂"}
📈 幸运指数：{★×N}（{加减分要点，如"+活动 +新券 −连吃"}）

🔮 签文：{从签文库按三档选用一条}

📅 近期机缘：{未来 3 天内开始的活动，最多 2 条；无则写"暂无，静候麦音"}

本黄历由实时数据推算，仅供参考，不构成营养或医疗建议；
餐品与活动以麦当劳官方渠道为准。
——————————————
```

## 填充示例（仅供格式参考，实际内容必须来自实时调用）

```markdown
📜 **麦门老黄历 · 2026-10-09 周五**
🕒 时辰：午时　|　班

——————————————
🔶 今日宜
1. 9.9 元早餐两件套今天还有，别错过（活动日历）
2. 先把 3 张麦麦省券领了再点（可领券）
3. 本月要过期的 8 积分，先花掉（积分账户）

⛔ 今日忌
1. 昨天刚吃过麦辣鸡腿堡，今天换口味（历史订单）
2. 别原价点单，包里还有可用券（卡包券）

🍀 幸运单品：麦旋风（约 230 kcal/份，营养库）
💰 财气：★★★★ — 4 张券在包，1 张今天到期
🎰 手气：★★★★ — 抽奖还剩 2 次，宜一发入魂
📈 幸运指数：★★★★（+活动 +新券 +周末临近 −连吃）

🔮 签文：金拱门开，券在袋中；今日出手，宜早不宜迟。

📅 近期机缘：10/13 起秋日限定活动上线，宜定闹钟

本黄历由实时数据推算，仅供参考，不构成营养或医疗建议；
餐品与活动以麦当劳官方渠道为准。
——————————————
```

## 卡片后的"懒人结论"

卡片输出之后，另起 2–3 句话收尾，模板：

> 懒人结论：今天就吃 {幸运单品或用户常点单品}，{领券/用券/抽奖的具体动作}，别 {最大忌条目}。

## 周运版（用户问"这周运势"）

用 `campaign-calendar` 覆盖未来 7 天，每天一行：

```markdown
周一 {★} 宜：… / 忌：…
周二 {★} 宜：… / 忌：…
…
周末 {★} 宜：… / 忌：…
```

末尾给一条"本周最大机缘"（未来 7 天内最值得关注的活动）。
